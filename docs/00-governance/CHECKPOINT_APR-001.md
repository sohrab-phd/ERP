## Authorized commands

Historically, after marker creation the agent was to submit these plain commands:

```text
git add -A
git commit -m "docs: approve phase 00 governance foundation"
```

Cursor transforms it before hook evaluation into:

```text
git commit --trailer "Co-authored-by: Cursor <cursoragent@cursor.com>" -m "docs: approve phase 00 governance foundation"
```

The marker stores this transformed form. The hook accepts only the plain command
or that exact fixed trailer form and denies arbitrary trailers. It revalidates
the complete changed set before `git add -A` and the complete staged set, Git
modes, and blob IDs before commit.
