## Governance

- Stable IDs are never reused.
- Entries are not deleted; they are closed, superseded, rejected, or retired.
- Phase documents link to entries instead of maintaining competing definitions.
- Initial entries from assimilation remain `proposed` until the owning phase
  validates them.
